## Install
Download the zip for your system from the link above, not "Source code". Quit Ableton Live
first.
**Windows:** unzip and copy the **whole folder** `Align.vst3` (whatever folder it sits
in) to `C:\Program Files\Common Files\VST3\`; Windows asks once for permission. Start Ableton
Live, Preferences > Plug-Ins > Rescan (Ableton Live 10: Preferences > File/Folder, "Use VST3
Plug-In System Folder" on, Rescan). If the window looks blurry, turn off Ableton Live's
"Auto-Scale Plug-in Window".
**macOS:** Finder > Go > Go to Folder, paste `~/Library/Audio/Plug-Ins/VST3/`, drop
`Align.vst3` there (the `.component` goes to `~/Library/Audio/Plug-Ins/Components/`).
Start Ableton Live and let it scan; it says the plugin cannot be verified, which is expected.
**Right after that:** System Settings > Privacy & Security, scroll down, **Open Anyway** next
to Align (the button disappears after a while; if it is gone, scan again). Then, in
Ableton Live, Preferences > Plug-Ins > Rescan. Once per download; needs an administrator
account. If the message says "damaged" instead of "cannot be verified", or the button never
appears: Terminal, `xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/"Align.vst3"`,
then rescan.

## Update
Same as install, over the old folder (quit Ableton Live first). Your presets and settings
stay. If the new version misbehaves, take the previous release from the same page; a project
saved with the newer version opens in the older one unless the release notes say otherwise.

## Uninstall
Delete `Align.vst3` from `C:\Program Files\Common Files\VST3\` or
`~/Library/Audio/Plug-Ins/VST3/` (and `Align.component` from
`~/Library/Audio/Plug-Ins/Components/`). Settings: `%APPDATA%\Oberli Audio\Align\` or
`~/Library/Application Support/Oberli Audio/Align/`. Presets: `Documents\VST3
Presets\Oberli Audio\Align\` or `~/Library/Audio/Presets/Oberli Audio/Align/`, only if you
also want your own presets gone.
